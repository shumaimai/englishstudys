# listening

リスニングの本体。**このフォルダだけで完結して動く**ようにしておく。

トップページから切り離しても単体で使えることが条件。
共通テストの利用許諾が下りなかった場合でも、ここだけは公開できる状態を保つ。

## 置くもの

- `index.html` … 本体（現時点では単一ファイル）

`kikikata-note.html` としてダウンロードしたものを `index.html` にリネームして
ここに置く。動作を確認してから、共通部分を `assets/` に切り出していく。

## 分割の方針（これから）

一枚にまとまっていると読みづらいので、順に切り出す。

- `assets/base.css` … 配色と字。トップページと共有する
- `assets/asr.js` … 音声認識まわり（モデルの受け取り、言語判定、暴走の検出）
- `assets/player.js` … 再生、文の繰り返し、ロック画面対応
- `assets/store.js` … 端末への保存

切り出すときは**一度に一つ**。動く状態を保ちながら進める。

## 用意してある音源と台本

`catalog.json` に載せた音源は、一覧から選ぶとその場で取ってきて再生できる。
取ってきたものは、手元から選んだファイルとまったく同じ扱いになる
（巻き戻しも速度も文字起こしもそのまま使える）。

```
listening/
├─ catalog.json            音源の一覧。base を書き替えれば置き場所を変えられる
└─ scripts/*.json          公式の台本（ブロックごと）
```

### 台本について

**これは文字起こしではない。** 試験の公式スクリプトをそのまま出している。
だから付箋も確信度も出さない。合っているものとして読める。

ただし**行ごとの時刻は分からない**。位置はブロック単位で、
行をタップしたときの飛び先は、行の長さの比で割った目安。
そう分かるように画面にも書いてある。

紙で勉強している人が、音だけ流したり、台本を見ながら
シャドーイングしたりするための欄として置いてある。

### 置き場所を変えるとき

`catalog.json` の `base` に URL を入れる。R2 に移すならここだけ。
いまは1音源9.2MBなので Cloudflare Pages にそのまま載る。
