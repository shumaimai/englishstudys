# listening

リスニングの本体。**このフォルダだけで完結して動く**ようにしておく。

トップページから切り離しても単体で使えることが条件。
共通テストの利用許諾が下りなかった場合でも、ここだけは公開できる状態を保つ。

## 置くもの

- `index.html` … 本体（現時点では単一ファイル）

`kikikata-note.html` としてダウンロードしたものを `index.html` にリネームして
ここに置く。動作を確認してから、共通部分を `assets/` に切り出していく。

## 分割の方針（これから）

一枚にまとまっていると読みづらいので、順に切り出す。

- `assets/base.css` … 配色と字。トップページと共有する
- `assets/asr.js` … 音声認識まわり（モデルの受け取り、言語判定、暴走の検出）
- `assets/player.js` … 再生、文の繰り返し、ロック画面対応
- `assets/store.js` … 端末への保存

切り出すときは**一度に一つ**。動く状態を保ちながら進める。
